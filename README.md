# Wedding Planner Website

## Overview

A wedding planning web application developed using Vue.js and Vite. The system helps users organize and manage wedding-related information through a clean and user-friendly interface.

## Features

- Wedding event planning
- Guest management
- Wedding information management
- Responsive user interface
- Interactive navigation
- Modern frontend design

## Technologies Used

### Frontend
- Vue.js
- Vite
- HTML5
- CSS3
- JavaScript

### Tools
- Visual Studio Code
- Git
- GitHub
